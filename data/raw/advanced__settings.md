Settings and Environment Variables¶In many cases your application could need some external settings or configurations, for example secret keys, database credentials, credentials for email services, etc.Most of these settings are variable (can change), like database URLs. And many could be sensitive, like secrets.For this reason it's common to provide them in environment variables that are read by the application.TipTo understand environment variables you can readEnvironment Variables.Types and validation¶These environment variables can only handle text strings, as they are external to Python and have to be compatible with other programs and the rest of the system (and even with different operating systems, as Linux, Windows, macOS).That means that any value read in Python from an environment variable will be astr, and any conversion to a different type or any validation has to be done in code.strPydanticSettings¶SettingsFortunately, Pydantic provides a great utility to handle these settings coming from environment variables withPydantic: Settings management.Installpydantic-settings¶pydantic-settingsFirst, make sure you create yourvirtual environment, activate it, and then install thepydantic-settingspackage:pydantic-settings$pipinstallpydantic-settings---> 100%$pipinstallpydantic-settings---> 100%It also comes included when you install theallextras with:all$pipinstall"fastapi[all]"---> 100%$pipinstall"fastapi[all]"---> 100%InfoIn Pydantic v1 it came included with the main package.
